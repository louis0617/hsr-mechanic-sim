# L1 vs L2 gap by damage source

Frozen numbers: [`../examples/e2e_acheron/frozen_outputs/l1_l2_source_gap_results.json`](../examples/e2e_acheron/frozen_outputs/l1_l2_source_gap_results.json).

Team `acheron_direct`, realistic 100-cycle window, seed=42, skill-rate pinned, no action-advance.

Ultimate-skill components that both models omit do not explain the remaining gap: the L1 ultimate rate is about half of L2, and L1 has no Jiaoqiu DoT.

## 0. 总判读

| 指标 | 值 |
|---|---:|
| L1 队伤 /100AV | 143010 |
| L2 队伤 /100AV | 178519 |
| 残差 (L1−L2)/L2 | **−19.9%** |
| L1 黄泉 ult 速率 | **0.347** |
| L2 黄泉 ult 速率 | **0.646** |

**主因不是终结技 MV 缺失**（次均终结技伤 L1 甚至略高于 L2：93300 vs 91300）。  
**主因是 L1 终结技速率约为 L2 的一半**，外加 **L1 无椒丘 DoT**。

把 L1 的黄泉 ult 速率钉成 L2 的 0.646 后：队伤 → 170968，残差 **−4.2%**。  
再计入 DoT 与泡影/假面实测覆盖后的量级见 §2。

队伤差距合计 L1−L2 ≈ −35509（与上表代数和一致量级）。

### 1.1 定位

1. **黄泉终结技（75% 差距）**：**速率** 0.347 vs 0.646；**次均接近且 L1 略高** → 不是缺 Rainblade MV（那会压低次均）。属 L1 残梦/四相/流量对终结技频率的低估。  
2. **椒丘 DoT（28.5%）**：已知候选成立——L1 Flow 无 DoT，L2 ≈ **1.01 万 /100AV**。  
3. **战技/普攻**：L1 **偏高**（泡影覆盖≈1 等近似），部分抵消上述低估。  
4. **其他成员（12.5%）**：含假面/易伤在队友伤上的差异等，非 。

**结论**：剩余 −19.9% **不能**归因于 终结技组件；应优先查 L1 终结技速率与 DoT 建模。

## 2. L1 新近似 × L2 实测替换

### 2.1 泡影覆盖（L1 假设 ≈1）

| | 值 |
|---|---:|
| L2 实测（黄泉伤害命中时目标已有泡影） | **77.1%**（306/397） |
| L1 假设 | 1.0 |
| 替换为 77.1% 后 L1 队伤 | 138477 |
| 残差 | **−22.4%**（比基准更差） |

测量：`_resolve_damage` 运行时挂钩（`effect_applied` **不进** `eng.events`，事后扫事件会得到假 0）。  
含义：假设≈1 **高估**泡影乘区，抬高了战技/普攻，部分掩盖终结技速率与 DoT 缺口。

### 2.2 假面覆盖（L1「basic×8」）

| | 值 |
|---|---:|
| L1 求解覆盖 | **1.0**（`lc_mask__*`） |
| 实现口径 | `source_action=basic`，`duration_turns=8`（=刷新持续 4×2） |
| L2 实测（黄泉行动时持假面） | **97.0%**（196/202） |
| 替换为 97% 后残差 | −20.0%（Δ 可忽略） |
| **由 L1 战技点流量推导** | 花火 pin 下 `u=0`，仅 basic 回 1 SP → 彩焰点≈0.599/100AV → 刷新≈0.150 → 相对黄泉回合时钟隐含覆盖 **≈0.44** |

「basic×8」**不是**从彩焰流量推出的稳态，而是人为把覆盖抬到饱和；与 SP 流量推导（≈0.44）矛盾。正式模型应按：恢复 SP（含溢出）/4 × 假面持续 4 / 消费时钟。本对照 pin 使花火大招速率为 0，流量法会**低估**真彩焰（L2 实测 97%）。

### 2.3 溢出「excess − 0.5×buffer」

| | 值 |
|---|---:|
| 单位包 excess | 0.5（来自 \(E[X^2]/(2E[X])\)，包大小 1） |
| L1 现式 | `excess − 0.5 × overflow_buffer(3)` → 常压成 **0** |
| **0.5×buffer 中的 0.5** | **无推导来源**（注释称 unit-packet mean，把 的 0.5 误接到 buffer 折扣） |
| L2 硬浪费 `dream_overflow_wasted` | **0**（本对照四相未顶满；quad 获得 47） |

方向（有四相缓冲则硬浪费≈0）与 L2 一致，但系数应用 **L2 实测浪费/回流**校准，不得保留无来源的 `0.5×buffer`。

### 2.4 组合替换（说明 −19.9% 可拆）

| 方案 | 残差 vs L2 |
|---|---:|
| 基准 L1 | −19.9% |
| 仅钉 L2 黄泉 ult 速率 | **−4.2%** |
| 泡影+假面改为实测覆盖 | −22.6% |
| 钉 ult 速率 + 两覆盖实测 | −7.8% |
| 基准 + 把 L2 DoT 1.01 万加进会计 | −14.2% |
| 钉 ult + 两覆盖 + DoT 会计 | **≈−2.1%** |

## 3. 四相断我 — 状态说明原文（补引用）

此前 g-2 仅引**赤鬼**行迹。终结技后回流的状态说明在技法 `130807` 内嵌：

**CN**（`StarRailRes/index_new/cn/character_skills.json`，`130807`）：

> 【四相断我】：施放终结技后黄泉获得#2[i]点【残梦】，并为敌方随机单体附上#2[i]层【集真赤】。

**EN**：

> Quadrivalent Ascendance: After using the Ultimate, Acheron gains #2[i] point(s) of Slashed Dream and inflicts #2[i] stack(s) of Crimson Knot on a single random enemy.

技法 ParamList：`[2, 1]` → 每层回流 **1** 残梦 + **1** 集真赤。  
赤鬼使层数上限为 3；N 层 → N×上述回流（与现实现一致）。

赤鬼（溢出获得，仍保留）：

> 当【残梦】达到上限时，每溢出1点【残梦】获得1层【四相断我】，使【四相断我】最多可以叠加至#2[i]层。
